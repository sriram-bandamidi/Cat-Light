# Cat & Light

A simple interactive Cat & Light switch project built using HTML, CSS, and JavaScript.

## Features

* Turn the light ON and OFF
* Interactive cat reaction
* Smooth UI design
* Beginner-friendly project
* Responsive layout

## Tech Stack

* HTML5
* CSS3
* JavaScript
